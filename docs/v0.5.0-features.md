# v0.5.0 Features

Release: **0.5.0** | Focus: modal UX, tempo sync, Session voice isolation, audio-slot guards

## Session voice isolation

| Scope | Menu | Behavior |
|-------|------|----------|
| `ClipSlot` (audio track) | Isolate Voice (ElevenLabs) | Exports clip audio → ElevenLabs isolation → replaces clip in same slot (loop preserved) |
| `AudioClip` | Isolate Voice (ElevenLabs) | Same pipeline on the selected session clip |

Arrangement isolation unchanged (`AudioTrack.ArrangementSelection` → take lane).

## Music modal

- **Set tempo** checked by default; slider = Live set tempo; optional write to `song.tempo` on generate
- **Duration** default **30 s**; **Auto duration** unchecked by default
- Layout: Seamless Loop above Model/Quality; inline half-width Model & Quality rows
- Title: **Generate Music**

## SFX modal

- **Auto duration** checked by default; toggle above duration slider
- Inline half-width Model & Quality rows
- Title: **Generate Sound Effects**

## Audio-track clip slot guards

Handlers for TTS, SFX, Music, Dialogue, Batch TTS, and Session voice isolation resolve slots via `isAudioClipSlot()` so MIDI-track slots no-op before opening modals. Ableton SDK `ClipSlot` scope still shows menu items on MIDI tracks (no `AudioTrack.ClipSlot` scope in API 1.0.0).
