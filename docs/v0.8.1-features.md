## Part control

Generate Music has a Part menu next to the duration slider. There is no ElevenLabs parameter for “this duration is a part.” Part modes send a composition plan instead of `prompt` and `music_length_ms`. `force_instrumental` is not sent with that plan.

| Part | What is generated |
| --- | --- |
| Full music | The previous request. The Instrumental genre still sets `force_instrumental` on the prompt path. |
| Instrumental part | One section named Instrumental. Styles ask for a single instrumental part. Negatives include vocals, singing, lyrics, and full song structure. |
| Instrument solo | One section named Solo. Description phrases are prefixed with `solo`. Negatives add full band, drums, and backing track unless the prompt asks for them. |
| Vocal solo | One section named Vocal Solo. Styles include `a cappella solo vocal`. Two or more description lines are the lyrics. A single line stays a style note and the model writes the words. Vocals, singing, and lyrics are not added as negatives. The Instrumental genre checkbox is disabled. |

Part modes turn auto duration off. The slider is the section length. Music v2 and v2.5 always enforce chunk duration, from 3 to 120 seconds. A longer part is several chunks with the same instruction. v1 uses the same styles on one section; lyric lines are filled only for a vocal solo.

`npm run check:build` checks these plans without calling the music API.
