# v0.3.0 Features

Release: **0.3.0** | BMad epic: `epic-v0.3.0`

## 1. Voice library picker (`voicePicker`)

**Problem:** Users had to paste raw ElevenLabs voice IDs.

**Solution:** Before TTS and voice-changer modals open, `ui.ts` calls `listVoices()` (`client.voices.search`, pageSize 50) and injects a `<select>` into `tts-modal.html` and `voice-modal.html`. Manual ID override field retained.

**Files:** `elevenlabs-client.ts`, `ui.ts`, `ui/tts-modal.html`, `ui/voice-modal.html`

## 2. Text-to-Dialogue (`dialogue`)

**User flow:** Right-click `ClipSlot` or `AudioTrack.ArrangementSelection` → **Generate Dialogue (ElevenLabs)** → pick Speaker A/B voices → script with `1:` / `2:` line prefixes → multi-voice audio clip.

**API:** `client.textToDialogue.convert({ inputs: [{ text, voiceId }, ...] })`

**Parser:** `src/dialogue.ts` — `parseDialogueScript()`

**Modal:** `ui/dialogue-modal.html`

## 3. Drum rack SFX (`drumRackSfx`)

**User flow:** Right-click `DrumRack` or a MIDI `ClipSlot` on a Drum Rack track → **Generate Drum Rack SFX** → configure up to 7 pad slots (type, style phrase, characteristics, duration) → generates SFX per enabled pad → loads into consecutive pads from start note via `ensureSimplerOnPad` + `Simpler.replaceSample`.

**Files:** `src/drum-io.ts`, `ui/drum-rack-sfx-modal.html`, `pipelines.pipelineDrumRackSfx`

## 4. Transcribe → MIDI lyrics (`transcribeToMidi`)

**User flow:** Right-click `AudioClip` or arrangement selection → **Transcribe to MIDI Lyrics** → Scribe with word timestamps → new `MidiTrack` named "ElevenLabs Lyrics" with C4 marker notes aligned to words.

**Files:** `elevenlabs-client.transcribeWithWords`, `midi-io.wordsToLyricNotes`, `pipelines.pipelineTranscribeToMidi`

**Note:** Marker pitch is C4 (60). Non-word tokens (laughter, etc.) are skipped.
