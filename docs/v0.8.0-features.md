# v0.8.0 Features

Release: **0.8.0** | Focus: Music v2.5, Eleven v4, arrangement locators, clip metadata, voice filters, Live 12 and 13 beta hosts.

Older specs stay as history: [v0.6.0](v0.6.0-features.md), [v0.5.0](v0.5.0-features.md), [v0.4.0](v0.4.0-features.md). Music inpainting itself shipped in [0.7.0](../CHANGELOG.md#v070); 0.8.0 changes its duration handling and model choice.

## Music v2.5

- Default model is `music_v2_5`. The music modal also offers `music_v2`. `music_v1` remains and is marked deprecated.
- v2 and v2.5 share chunk plans. Generation text limits are 6132 characters, 30 lines, and 200 characters per line.
- Extend, similar, and seamless-loop inpainting omit the source duration so the new audio is not truncated to the source clip. Regenerate still uses the source duration.
- Stored song records keep the planned output duration (generation chunks plus audio-reference ranges).
- The inpaint modal has its own model picker (v2.5 or v2) and quality picker.
- `npm run test:music` generates 10 seconds with `composeDetailed`, checks the composition plan has sections, then runs one seamless-loop inpaint. An instrumental prompt may have zero word timestamps.

## Eleven v4

- Dialogue modal: Eleven v3 (default) or Eleven v4, similarity, optional context before and after (100 characters), and an arrangement-locator checkbox.
- Text-to-speech modal: Flash v2.5 (default), Eleven v4, and Eleven v3. v4 uses the same speed, stability, similarity, and style controls as Flash. v3 keeps its three-step stability control and skips pronunciation dictionaries.
- API smoke (`npm run check:api`) confirms v4 speech, a two-line v4 dialogue, and dialogue `voiceSegments` timing.

## Arrangement locators

Optional, arrangement scope only, off by default.

| Source | Locator |
| --- | --- |
| Music composition plan | One cue per section or chunk |
| Dialogue `voiceSegments` | Speaker A, B, or C |
| Transcript words | Sentences split on punctuation or a pause longer than 0.8 seconds |

Transcribe and Transcribe-to-MIDI ask before rendering. Cancel skips the render. Session clip-slot imports do not add locators.

`npm run smoke:live:12` and `smoke:live:13` run a Live self-test (cue name, clip name and color, take-lane name) only when that Live beta is already open. `npm run smoke` does not start or connect to Live. The self-test passed on Live 13.0b21 during development. Live 12 still needs a manual pass.

## Clip names and colors

Generated clips are named `EL {feature}: …` (60 characters) and colored by feature. Voice-changer and isolation take lanes are named the same way.

## Voice filters

Voice search loads up to three pages (150 voices). The speech, voice, and dialogue modals filter that list in the page by search, gender, age, accent, language, and category. Cloned voices from storage are merged with category `cloned`. The last filter is saved in `elevenlabs-config.json` because Live does not keep modal state between opens.

## Live hosts

| Host | Status |
| --- | --- |
| Live 12.4.15 beta | Supported. API 1.0.0. Extension Host Node 24.14.1. |
| Live 13.0 beta | Supported. Stay on API 1.0.0. Do not opt into experimental 1.0.1. |
| Retail Live 12.4.x | No Extension Host. |

`npm run start:12` and `npm run start:13` pick the matching beta. Dev builds need Node ≥ 24.16.0.

## Tests

| Command | What it does |
| --- | --- |
| `npm run smoke` | Build, fake-host command open/cancel, API smoke. Does not start Live. |
| `npm run smoke -- --music` | Also runs the music v2.5 credit test. |
| `npm run check:api` | Voices, Flash speech, v4 speech probe, v4 dialogue and timestamps, 1-second SFX, Scribe on the speech file. |
| `npm run smoke:host` | Loads `dist/extension.js` under each Live bundled `node.exe` without opening Live. |

GitHub Actions CI is `workflow_dispatch` only.
