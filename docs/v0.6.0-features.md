# v0.6.0 Features

Release: **0.6.0** | Focus: Drum Rack SFX pad-slot refactor, API key onboarding & management

## Drum Rack SFX (pad-slot modal)

| Scope | Menu | Behavior |
|-------|------|----------|
| `DrumRack` | Generate Drum Rack SFX (ElevenLabs) | Opens **Drum Rack SFX** modal |
| MIDI `ClipSlot` | Generate Drum Rack SFX (ElevenLabs) | Resolves Drum Rack on track; auto-inserts empty Drum Rack when track has no devices |

### Modal layout

- **7 pad slots** — Enable, Type (Kick, Snare, Open Hat, Closed Hat, Rimshot, Perc, Clap, Other), style phrase, editable characteristics, Duration + Auto
- **Default:** only Pad 1 enabled (not persisted — always opens with Pad 1 only)
- **Build entire drum kit** — enables all 7, presets types, randomizes style phrases
- **Root C** — C-2, C-1, C0, C1, C2, C3 (default **C1** / MIDI 36)
- **Pad mapping** — **Sequential** (consecutive from root C) or **General MIDI** (type-based GM offsets from root C)
- **Kick key** / **Snare key** — optional pitch character for Kick- and Snare-type pads
- **Overwrite occupied** — replace pads that already have samples
- **SFX v2 only** — no model picker (always `eleven_text_to_sound_v2`)

Each enabled pad is one ElevenLabs SFX generation. Missing Simplers are created automatically. Delivery rules (0.25 s lead-in, kit-matched level, avoid terms) are appended to every prompt automatically.

### Removed (from prior drum modal)

- Variants / loop / auto-load consecutive variants
- Single-pad Simpler picker requirement
- SFX v1 model option

## API key onboarding & management

- **First-run prompt** — paste API key when neither `ELEVENLABS_API_KEY` nor `api-key.txt` is configured
- **Manage ElevenLabs API Key** — Drum Rack and Audio Track context menus
- **Show / hide** saved key in manage modal; validate on save; remove saved file option
- **Pre-progress resolution** — API key resolved before ElevenLabs progress dialogs

## Persistence

`elevenlabs-config.json` → `drumKit` stores pad layout (type, stylePhrase, duration, autoDuration), root C, pad mapping mode, overwrite flag, kick key, snare key. **Enable state is not persisted.** Characteristics are re-derived from drum type on open (not persisted).
