# v0.4.0 Features

Release: **0.4.0** | BMad epic: `epic-v0.4.0`

## 1. Music stem separation (`stemSeparation`)

**Flow:** Audio clip or arrangement selection → choose 2- or 6-stem layout → `music.separateStems` → ZIP → one `AudioTrack` per stem with auto mixer levels.

| Stem filename hint | Mixer level |
|--------------------|-------------|
| vocals | 0.90 |
| drums | 0.85 |
| bass | 0.80 |
| guitar/piano/synth | 0.78 |
| other/instrumental | 0.75 |

**Files:** `elevenlabs-client.separateMusicStems`, `zip-io.ts`, `pipelines.pipelineStemSeparation`

## 2. Instant voice clone (`voiceClone`)

**Flow:** Clip or arrangement → name → `voices.ivc.create` → voice ID saved to `{storageDirectory}/elevenlabs-config.json`.

Cloned voices appear in voice picker after cache invalidation (or within 5 minutes).

## 3. Forced alignment → MIDI (`forcedAlignmentMidi`)

**Flow:** User pastes exact lyrics → `forcedAlignment.create` → word timestamps → MIDI lyric markers (more precise than Scribe auto-transcribe).

Differs from **Transcribe → MIDI** which uses Scribe STT without a user transcript.

## 4. Pronunciation dictionary (`pronunciationDictionary`)

**Flow:** Right-click any **AudioTrack** → Add Pronunciation Rule → creates dictionary via `createFromRules` → optionally set active.

Active dictionary is passed as `pronunciationDictionaryLocators` on all TTS generations.

**Storage:** `elevenlabs-config.json` in `storageDirectory`.
